# AVELON Marketplace AI — MVP Interface

## 1. Данные товара

Пользователь вводит:

- фотографии товара;
- текст/описание от поставщика;
- закупочную цену;
- доступные размеры;
- материал;
- дополнительную информацию.

## 2. Кнопка генерации

Кнопка:

Создать карточку объявления

## 3. Результат AI

После обработки показать:

### Характеристики
- бренд;
- тип товара;
- цвет;
- пол;
- материал;
- размеры;
- категория Avito.

### Объявление
- SEO-заголовок до 50 символов;
- количество символов заголовка;
- готовое описание;
- рекомендованная цена;
- закупочная цена;
- ожидаемая прибыль.

### Аналитика
- рекомендуемый город;
- конкуренция;
- вероятность продажи;
- ожидаемый срок продажи.

### Фотографии
- рекомендуемый порядок фотографий;
- рекомендации по улучшению фотографий.

## 4. Первый MVP

На первом этапе публикация на Avito выполняется вручную.

AVELON Marketplace AI только создаёт готовую карточку объявления.
